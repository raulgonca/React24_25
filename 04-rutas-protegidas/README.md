# Navegacion Basica con protecion

## Objetivo

Implementar una navegacion a traves de rutas protegidas.

## Descripcion

1. Home (/) Pagina publica con el boton del login
2. Perfil (/profile) Pagina privada con informacion del usuario
3. Dashboard (/dashboard) Pagina privada con estadisticas

## Requisitos

1. Vite
2. React Router Dom v7
3. Simular el uso de un TOKE que valide el login (guardado en LocalStorage)
4. Pagina de errores gestionada por nosotros
