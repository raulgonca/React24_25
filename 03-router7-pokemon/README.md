# Proyecto de Pokemon con uso de React Router v7

Se pretende realizar un proyecto que utilice las siguientes tecnologías :

> - React Router en su version 7
> - Contexto Globales
> - Libreria Sonner para notificaciones
> - Estilado con Tailwind CSS


El Scaffolding de este proyecto va a ser el siguiente :

```text
src/
|-components/
|    |-Navbar.jsx 
|-context/
|    |-PokemonContext.jsx
|-layouts/
|    |-RootLayout.jsx
|-pages/
|    |-Home.jsx
|    |-Search.jsx
|    |-PokemonDetail.jsx
|    |-Favorites.jsx
|routers/
|    |-Router.jsx
|    |-paths.js
|App.jsx
|main.jsx

```
